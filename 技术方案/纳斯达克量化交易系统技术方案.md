# 纳斯达克指数量化交易系统技术方案

## 1. 项目概述

### 1.1 项目背景

本项目基于 [autoresearch](https://github.com/karpathy/autoresearch) 的自主实验迭代理念和微软 [Qlib](https://github.com/microsoft/qlib) 量化投资平台的框架设计，构建一个面向**美股纳斯达克指数（NASDAQ）成分股**的量化交易系统。

**autoresearch** 的核心理念：
- 给 AI 智能体一个真实的训练环境，让其自主实验
- 修改代码 → 训练 → 评估 → 保留/丢弃 → 循环
- 固定时间预算、单一评估指标、自主进化

**Qlib** 的核心能力：
- 完整的量化投资 ML Pipeline（数据处理 → 模型训练 → 回测 → 分析）
- 丰富的模型库（LightGBM, LSTM, GRU, Transformer, HIST 等）
- 高性能数据服务器
- Alpha因子挖掘与组合优化

### 1.2 项目目标

构建一个完整的纳斯达克量化交易系统，具备以下能力：

1. **数据采集与处理**：自动获取纳斯达克成分股的行情数据（OHLCV + 技术指标）
2. **因子工程**：构建 Alpha158 多因子体系
3. **模型训练**：支持多种 ML 模型（LightGBM、LSTM、GRU 等）的训练与预测
4. **策略回测**：基于模型预测信号生成交易决策并回测
5. **风险分析**：提供完整的绩效分析报告
6. **自主进化**：借鉴 autoresearch 理念，支持模型的自主迭代优化

### 1.3 核心指标

| 指标 | 说明 |
|------|------|
| IC (Information Coefficient) | 预测值与实际收益率的相关系数 |
| ICIR (IC Information Ratio) | IC 的均值/标准差，衡量预测稳定性 |
| 年化收益率 (Annualized Return) | 策略的年化收益 |
| 最大回撤 (Max Drawdown) | 最大资产回撤幅度 |
| 夏普比率 (Sharpe Ratio) | 风险调整后收益 |
| 超额收益 (Excess Return) | 相对基准的超额收益 |

### 2.2 模块设计

#### 模块 1: 数据层 (`nasdaq_quant/data/`)

**职责**：纳斯达克成分股数据的获取、清洗、存储

- `data_collector.py` — 从 Yahoo Finance 采集 OHLCV 日频数据
- `data_processor.py` — 数据清洗、格式转换、存入 Qlib 格式
- `nasdaq_components.py` — 纳斯达克100成分股列表管理

**数据范围**：
- 标的：纳斯达克100指数成分股（AAPL, MSFT, GOOGL, AMZN, META, NVDA 等）
- 频率：日频（Daily）
- 时间跨度：2015-01-01 至今
- 字段：Open, High, Low, Close, Volume, Adj Close

#### 模块 2: 因子工程层 (`nasdaq_quant/factors/`)

**职责**：构建预测因子（Alpha因子）

采用 Qlib Alpha158 因子集，包含 158 个因子：

| 因子类别 | 数量 | 示例 |
|---------|------|------|
| 价格动量 | 30+ | ROC, MOM, RSI, MACD |
| 波动率 | 20+ | ATR, BBANDS, STD |
| 成交量 | 15+ | VWAP, OBV, VR |
| 价格形态 | 25+ | K线形态, 缺口 |
| 统计指标 | 30+ | CORR, BETA, SKEW, KURT |
| 技术指标 | 38+ | SMA, EMA, WMA, DEMA |

#### 模块 3: 模型训练层 (`nasdaq_quant/models/`)

**职责**：训练预测模型，生成收益预测信号

支持的模型：

| 模型 | 类型 | 适用场景 |
|------|------|---------|
| LightGBM | 梯度提升树 | 基线模型，稳健性好 |
| Linear | 线性回归 | 快速基线 |
| LSTM | 循环神经网络 | 序列特征建模 |
| GRU | 门控循环单元 | 轻量序列模型 |
| GATs | 图注意力网络 | 股票关系建模 |
| Transformer | 自注意力 | 长序列依赖 |

**训练标签**：
- 目标变量：未来 N 日收益率 `Ref($close, -N) / $close - 1`
- 默认 N=2（预测未来2日收益率）

#### 模块 4: 策略与回测层 (`nasdaq_quant/strategy/`)

**职责**：基于模型预测信号，生成交易决策并回测

- **TopK-Dropout 策略**：每期选择预测得分最高的前K只股票
- **等权组合**：被选股票等权分配资金
- **调仓频率**：每日/每周调仓
- **交易成本**：默认单边 0.1% 佣金 + 0.1% 滑点

**回测引擎**：
- 支持逐日回测
- 自动计算交易成本
- 支持做多/做空

#### 模块 5: 分析与展示层 (`nasdaq_quant/analysis/`)

**职责**：生成分析报告和可视化

- IC 分析（日IC、月IC、IC分布）
- 累计收益曲线
- 分组收益分析
- 最大回撤分析
- 换手率分析

## 4. 因子工程设计

### 4.1 Alpha158 因子体系

Alpha158 是 Qlib 提供的标准化因子集，在此基础上进行适配：

**基础价量因子**：
```python
# 价格相关
KMID = ($close - $open) / $open              # K线中间价
KLEN = ($high - $low) / $open                # K线长度
KMID2 = ($close - $open) / ($high - $low)    # 归一化K线

# 量价关系
VWAP = ($volume * ($high + $low + $close) / 3) / $volume
VR   = Mean($volume, 5) / Mean($volume, 20)  # 量比
```

**动量因子**：
```python
ROC_5   = Ref($close, -5) / $close - 1     # 5日收益率
ROC_10  = Ref($close, -10) / $close - 1    # 10日收益率
ROC_20  = Ref($close, -20) / $close - 1    # 20日收益率
ROC_60  = Ref($close, -60) / $close - 1    # 60日收益率
RSI_14  = 100 - 100/(1+RS)                  # 14日RSI
```

**波动率因子**：
```python
STD_5   = Std($close / Ref($close, 1) - 1, 5)   # 5日波动率
STD_20  = Std($close / Ref($close, 1) - 1, 20)  # 20日波动率
ATR_14  = Mean(MAX($high-$low, ABS($high-Ref($close,1)), ABS($low-Ref($close,1))), 14)
```

**技术指标因子**：
```python
MA_5    = Mean($close, 5)
MA_10   = Mean($close, 10)
MA_20   = Mean($close, 20)
MA_60   = Mean($close, 60)
MACD    = EMA($close, 12) - EMA($close, 26)
```

### 4.2 标签构造

```python
# 未来N日收益率（默认N=2）
label = Ref($close, -2) / Ref($close, -1) - 1
```

## 6. 交易策略设计

### 6.1 TopK-Dropout 策略

```python
策略参数:
  topk: 30          # 持仓股票数量
  n_drop: 5         # 每次调仓最多卖出数量
  signal: pred_score  # 预测信号
  频率: 每日调仓
```

**调仓逻辑**：
1. 根据模型预测分数对所有股票排序
2. 当前持仓中，排名跌出 Top-K 的股票卖出（最多卖 n_drop 只）
3. 将空出的资金买入排名最高的非持仓股票
4. 等权分配

### 6.2 交易成本模型

```python
交易成本:
  买入佣金: 0.001 (0.1%)     # 美股一般更低
  卖出佣金: 0.001 (0.1%)
  滑点:    0.001 (0.1%)
  印花税:  0.0   (美股无印花税)
```

### 6.3 风险控制

- **最大持仓限制**：单只股票最大仓位 10%
- **止损规则**：单只股票当日亏损超过 5% 强制卖出
- **仓位管理**：总仓位 80%-100%

## 7. 回测与评估设计

### 7.1 回测框架

```python
回测参数:
  基准: NASDAQ 100 Index (NDX)
  初始资金: $1,000,000
  交易费用: 单边 0.1%
  回测区间: 2023-01-01 ~ 2024-12-31
  交易频率: 日频
```

### 7.2 评估指标体系

**信号评估**：
| 指标 | 公式 | 优秀标准 |
|------|------|---------|
| IC | corr(pred, actual_return) | > 0.05 |
| ICIR | mean(IC) / std(IC) | > 1.5 |
| Rank IC | rank_corr(pred, actual_return) | > 0.05 |

**组合评估**：
| 指标 | 公式 | 优秀标准 |
|------|------|---------|
| 年化收益 | (1+total_return)^(252/days) - 1| > 15% |
| 夏普比率 | mean(excess_return) / std(excess_return) * √252 | > 1.5 |
| 最大回撤 | max(peak - trough) / peak | < 20% |
| 换手率 | avg(daily_turnover) | < 30% |
| Calmar 比率 | annualized_return / max_drawdown | > 1.0 |

## 8. 自主进化模块设计

### 8.1 借鉴 autoresearch 的进化机制

参考 autoresearch 的 experiment loop，实现模型的自主迭代优化：

```
LOOP:
1. 加载当前最优配置 (config.yaml)
2. AI Agent 修改超参数/模型结构/因子组合
3. 运行训练 + 回测
4. 比较 ICIR / 夏普比率
5. 如果改进 → 保留 (keep)
6. 如果退步 → 丢弃 (discard)
7. 记录到 results.tsv
8. 重复
```

### 8.2 可调范围

| 维度 | 可调参数 | 范围 |
|------|---------|------|
| 数据 | 因子窗口期 | 5, 10, 20, 60 |
| 数据 | 标签天数 N | 1, 2, 3, 5 |
| 模型 | LightGBM 超参 | learning_rate, depth, leaves |
| 模型 | LSTM 层数/维度 | 1-4 层, 32-256 维 |
| 策略 | TopK 数量 | 10, 20, 30, 50 |
| 策略 | 调仓频率 | 日/周 |

## 12. 风险提示

1. **历史回测不代表未来表现**：量化模型基于历史数据训练，无法保证未来的盈利性
2. **市场风格切换**：纳斯达克以科技股为主，市场风格切换时可能出现较大回撤
3. **数据质量风险**：Yahoo Finance 数据可能存在缺失或错误
4. **过拟合风险**：模型可能对训练数据过拟合，需要严格的样本外检验
5. **流动性风险**：部分小市值成分股可能存在流动性不足的问题
6. **本系统仅供研究学习使用，不构成任何投资建议**

## 14. 进阶设计要点（来自 nasdaq-quant-plan 方案学习）

> 以下内容整合自 `nasdaq-quant-plan.md` 中值得借鉴的设计理念与架构思想。

### 14.1 AI 智能体自主实验循环（Autonomous Experiment Loop）

核心理念：将 autoresearch 的"修改→训练→评估→保留/丢弃"范式应用到量化领域。

**设计哲学对照表：**

| 原则 | autoresearch 原始设计 | AutoQuant 量化对应 |
|------|----------------------|-------------------|
| 单文件修改 | 智能体只改 `train.py` | 智能体只改 `strategy.py` |
| 固定时间预算 | 5分钟训练 | 固定回测时间窗口（3年历史数据） |
| 单一评估指标 | `val_bpb`（越低越好） | `sharpe_ratio`（越高越好） |
| 自主循环 | 修改→训练→评估→保留/丢弃 | 修改→回测→评估→保留/丢弃 |
| 研究指令 | `program.md` | `program.md`（量化版） |

**自主循环流程：**
```
读取 program.md 指令
       ↓
分析 results.tsv 历史实验
       ↓
提出实验假设（更换模型/调整因子/修改策略/调超参）
       ↓
修改 strategy.py → git commit → 运行 backtest
       ↓
提取 sharpe_ratio / max_drawdown 指标
       ↓
sharpe 改善？ → YES: keep / NO: git reset discard
       ↓
记录到 results.tsv → 循环
```

**决策规则：**
- 主指标 `sharpe_ratio` 提升 → keep
- `sharpe_ratio` 下降或持平 → discard
- 回测崩溃 → crash
- 硬约束：`max_drawdown` > -30% 自动视为 crash

**results.tsv 格式规范（含 Git Commit 追踪）：**
```
commit	sharpe	max_dd	annual_ret	status	description
a1b2c3d	1.230	-0.182	0.198	keep	baseline: LightGBM + Alpha158 + TopK30
b2c3d4e	1.456	-0.155	0.221	keep	tune LR to 0.02 + increase num_leaves to 300
c3d4e5f	1.102	-0.245	0.187	discard	switch to LSTM (worse sharpe)
d4e5f6g	0.000	0.000	0.000	crash	transformer OOM on GPU
```

### 14.2 单文件策略隔离设计（strategy.py）

将因子、模型、策略、超参数集中到一个文件 `strategy.py` 中，作为智能体唯一可修改的文件。其余模块（数据准备、回测引擎）保持不变，确保实验结果的可比较性。

**strategy.py 结构：**
```python
# 特征工程配置
FEATURE_SET = "alpha158"   # "alpha158" | "alpha360" | "custom"
CUSTOM_FEATURES = []       # 自定义因子表达式

# 模型配置
MODEL_TYPE = "lightgbm"    # 模型类型
LIGHTGBM_PARAMS = {...}    # 超参数
LSTM_PARAMS = {...}

# 交易策略配置
STRATEGY_TYPE = "topk_dropout"
TOPK = 30
N_DROP = 5

# 风控配置
MAX_POSITION_WEIGHT = 0.10
STOP_LOSS = -0.08
MAX_DRAWDOWN_LIMIT = -0.20
```

### 14.3 风控体系增强

**计划方案中识别的关键风控要素：**

| 风控维度 | 参数 | 说明 |
|---------|------|------|
| 个股止损 | `STOP_LOSS = -0.08` | 单只股票亏损超过8%强制卖出 |
| 组合回撤限制 | `MAX_DRAWDOWN_LIMIT = -0.20` | 组合回撤超20%暂停交易 |
| 单只仓位上限 | `MAX_POSITION_WEIGHT = 0.10` | 单只股票最大10%仓位 |
| 滑点模拟 | `SLIPPAGE = 0.001` | 交易滑点0.1% |

### 14.4 模型集成策略

采用加权集成方式，根据验证集 IC 表现动态调整权重：

```python
# 多模型集成
ensemble_score = w1 * lgb_score + w2 * lstm_score + w3 * gru_score

# 权重基于验证集 ICIR 归一化
w_i = max(icir_i, 0) / sum(max(icir_j, 0))
```

支持的集成方式：
- **equal**：等权平均
- **ic_weighted**：基于验证集 IC 加权
- **rank_average**：预测排名平均

### 14.8 与 autoresearch 的核心差异

| 维度 | autoresearch | AutoQuant |
|------|-------------|-----------|
| 领域 | NLP/LLM 预训练 | 量化交易 |
| 修改目标 | 模型架构+优化器 | 因子+模型+策略 |
| 评估方式 | 实时训练5分钟 | 历史回测（固定数据） |
| 计算需求 | 必须GPU (H100) | LightGBM仅需CPU，DL需GPU |
| 单次实验时长 | ~5分钟 | ~2-5分钟 |
| 过夜实验数 | ~100次 | ~100-200次 |
| 风险 | 浪费算力 | 策略过拟合 |
